# Constraints for every `uv pip install` in this image and all its children
# (set via UV_CONSTRAINT in the Dockerfile). A constraint doesn't install anything;
# it only stops uv from moving a package outside these bounds.
#
# Keep this list minimal: everything here applies to every image. A constraint
# like jupyterlab>=4 would break every e2x build, because nbgrader 0.8 (via
# e2xgrader) needs jupyterlab<4.

# nbgrader 0.8 (via e2xgrader) needs jupyter-server 1.x, so every e2x variant
# ends up there anyway. Pinning it here, at the root, keeps all images on the
# same server version, so the e2x layer doesn't have to downgrade it again.
# (Notebook 6 itself would also run on jupyter-server 2.)
jupyter-server<2.0.0
